# Member 2 starts here

Follow `docs/member_2_ingredients_plate.md`. Create `models.py`, `system.py` and
`renderer.py` in this folder. Import the existing records from
`restaurant.shared.contracts`; do not redefine them.

Start with pure state logic: collect, add to plate, remove, discard, snapshots,
revision-checked clear and reset. Then add your isolated demo and tests. The
player selects the target; your system does not need keyboard or movement code.

No ingredient/plate behavior is implemented by this starter.
