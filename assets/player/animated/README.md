# Classic Chef animation frames

The animated game sprites are in `assets/player/animated/`. The game uses one selectable chef, Classic Chef. The animation atlas set was generated with built-in ImageGen using the original directional chef frames as the character reference. Each usable pose was exported to its own transparent PNG, aligned at the hat center and shoe baseline, then checked in Arcade. The rear and front walk cycles alternate lead feet. Each direction has a dedicated idle pose and the plate is part of the carrying frame. The knife is part of the chopping animation.

Frames use a 122 × 104 transparent canvas. The chef is 92 source pixels tall and rendered at 2×, anchored at the same 32 × 20 world-pixel foot hitbox. This lets the legs and shoes read clearly without widening physical collisions. The preparation bench rendering draws food and chopped pieces independently from the chef.
